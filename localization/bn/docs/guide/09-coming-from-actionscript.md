> এটি [ইংরেজি মূল লেখার](../../../../docs/guide/09-coming-from-actionscript.md) অনুবাদ। পার্থক্য থাকলে ইংরেজি সংস্করণটিই সঠিক। অনুবাদটি AI-এর সাহায্যে করা এবং লেখক যাচাই করেছেন।

# ৯. ActionScript 3 থেকে আসছেন?

RuneScript ActionScript 3 থেকে *অনুপ্রাণিত*, কিন্তু এর সঙ্গে সামঞ্জস্যপূর্ণ নয়।
AS3 কোড না বদলে কম্পাইল হবে না। মূল পার্থক্যগুলো:

## ঘোষণা: আগে টাইপ, `function` নেই, `var` নেই

ActionScript 3:

```as3
package {
    public class Greeter {
        public function sayHi(message:String, times:int):void {
            for (var i:int = 0; i < times; i++) {
                trace(message);
            }
        }
    }
}
```

RuneScript (v0.1-এ এখনো ক্লাস নেই, তাই এটি একটি টপ-লেভেল ফাংশন):

```actionscript
package main;

public void sayHi(string message, int times) {
    for (int i = 0; i < times; i++) {
        trace(message);
    }
}

protected int main() {
    sayHi("hi", 2);
    return 0;
}
```

| AS3 | RuneScript |
|---|---|
| `package x { … }` | `package x;` |
| `function f(a:int):int` | `int f(int a)` |
| `var n:int = 0;` | `int n = 0;` |
| `String`, `Boolean` | `string`, `bool` |
| সেমিকোলন ঐচ্ছিক | সেমিকোলন বাধ্যতামূলক |
| `*` / টাইপ বাদ দেওয়া চলে | প্রতিটি ভেরিয়েবল, প্যারামিটার ও ফাংশনের টাইপ স্পষ্ট করে লেখা; কোনো `any` নেই |
| `Array`, `Vector.<String>` | `Array<string>`: প্রতিটি এলিমেন্টের টাইপ ঘোষিত টাইপই |
| `"n=" + 5` | `"n=" + (string) 5` অথবা `$"n={5}"`: `+` কখনো সংখ্যা রূপান্তর করে না |
| `null`, `*` | কোনোটিই নেই: কোনো মান কখনো অনুপস্থিত বা টাইপহীন হয় না ([অধ্যায় ১৭](17-no-null-any-generics.md)) |

## আরও কঠোর পূর্ণসংখ্যা

| কোড | AS3 | RuneScript |
|---|---|---|
| `var u:uint = -1;` | হয়ে যায় 4294967295 | কম্পাইল এরর `ASX-TYPE-007` |
| `uint` ← `int` ভেরিয়েবল | নিঃশব্দে রূপান্তরিত হয় | কম্পাইল এরর `ASX-TYPE-004` |
| `int + uint` | নিঃশব্দে রূপান্তরিত হয় | কম্পাইল এরর `ASX-TYPE-011` |
| `int.MAX_VALUE + 1` | ঘুরে একটি ঋণাত্মক সংখ্যা হয়ে যায় | কখনো নিঃশব্দে ঘোরে না (v0.1: রানটাইম এরর `ASX-RUN-002`) |
| `7 / 2` | `3.5` (একটি `Number`) | `3` (পূর্ণসংখ্যার ভাগ) |

## আরও কঠোর শর্ত

AS3-তে `if (count)` বা `if (name)` লেখা যায়। RuneScript-এ একটি `bool` লাগে, তাই
লিখুন `if (count != 0)`।

## ক্লোজার

AS3-এর ক্লোজার বাইরের ফাংশনের ভেরিয়েবল ধরে রাখে (capture করে)। RuneScript-এর
ফাংশন তা করে না: নেস্টেড ফাংশন ও ল্যাম্বডা কেবল নিজেদের প্যারামিটার ও লোকাল
ভেরিয়েবল, আর অন্যান্য ফাংশন ব্যবহার করতে পারে। তার বদলে মানগুলো প্যারামিটার হিসেবে
পাঠান।

| AS3 | RuneScript |
|---|---|
| `function(a:int):int { return a * 2; }` | `(int a) => a * 2` |
| `var f:Function = add;` | `int(int, int) f = add;` (টাইপসহ) |
| `public function f():void` | `public void f()` (অ্যাক্সেস মডিফায়ার বাধ্যতামূলক) |

## ব্লক স্কোপ

AS3-তে লুপের ভেতরে ঘোষিত `var` পুরো ফাংশনে দেখা যায়। RuneScript-এ একটি ভেরিয়েবল
কেবল তার ব্লকেই থাকে। নেস্টেড ব্লকের একটি ভেরিয়েবল বাইরের ব্লকের কোনো ভেরিয়েবলকে
আড়াল করতে পারে, একটি সতর্কবার্তাসহ, কিন্তু একই ব্লকের কোনোটিকে নয়। AS3-এর মতো
`int n;` `0` দিয়ে শুরু হয়; AS3-এর বিপরীতে `string s;` শুরু হয় `""` দিয়ে, কারণ কোনো
`null` নেই।

## প্রবেশবিন্দু

AS3 প্রোগ্রাম শুরু হয় একটি ডকুমেন্ট ক্লাস থেকে। RuneScript প্রোগ্রাম শুরু হয়
একটি টপ-লেভেল `protected int main()` ফাংশন থেকে, কোনো ক্লাস লাগে না।

## AS3-এর মতোই

- `trace(a, b, c)` তার আর্গুমেন্টগুলো স্পেস দিয়ে আলাদা করে দেখায়।
- `public`, `protected` ও `private` হলো দৃশ্যমানতার মডিফায়ার (এদের সঠিক নিয়ম এখনো
  নকশা করা হচ্ছে)।
- `int` ও `uint` পরিচিত পূর্ণসংখ্যার নাম, এবং `int` ডিফল্টভাবে 32-বিট।
- C-ধাঁচের `if`, `while`, `for`, `break`, `continue`, `&&`, `||` ও `!`।

## এখনো নেই

ক্লাস, ইন্টারফেস, `static`, `push` ও `pop`-এর বাইরের অ্যারে-মেথড,
মেটাডেটা, E4X XML, এবং গ্রাফিক্স (একটি নেটিভ গ্রাফিক্স প্যাকেজের পরিকল্পনা আছে)। দেখুন
