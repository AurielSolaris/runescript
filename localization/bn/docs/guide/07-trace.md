> এটি [ইংরেজি মূল লেখার](../../../../docs/guide/07-trace.md) অনুবাদ। পার্থক্য থাকলে ইংরেজি সংস্করণটিই সঠিক। অনুবাদটি AI-এর সাহায্যে করা এবং লেখক যাচাই করেছেন।

# ৭. `trace` দিয়ে আউটপুট

`trace` হলো কিছু দেখানোর (প্রিন্ট করার) বিল্ট-ইন উপায়; নামটি ActionScript থেকে
নেওয়া। এটি `void` ছাড়া যেকোনো টাইপের যতগুলো খুশি আর্গুমেন্ট নেয়। সেগুলোকে একটি
করে স্পেস দিয়ে আলাদা করে, শেষে একটি নতুন লাইন দিয়ে, স্ট্যান্ডার্ড আউটপুটে লেখে।

```actionscript
package main;

protected int main() {
    trace("Hello");                 // Hello
    trace("x =", 42);               // x = 42
    trace(1, -2, true, "three");    // 1 -2 true three
    trace();                        // (empty line)
    return 0;
}
```

| মান | যেভাবে দেখায় |
|---|---|
| `int`, `sint`, `uint` | দশমিক সংখ্যা, যেমন `-42` |
| `float`, `float32`, `float64` | ActionScript যেভাবে সংখ্যা দেখায়: `64`, `0.5`, `1e+21`, `NaN` ([অধ্যায় ১৩](13-floats-and-conversions.md)) |
| `bool` | `true` / `false` |
| `string` | লেখাটি নিজেই, উদ্ধৃতিচিহ্ন ছাড়া |
| `char` | অক্ষরটি নিজেই, যেমন `é` |
| একটি এরর | তার নাম ও বার্তা, যেমন `RangeError: too big` ([অধ্যায় ১৪](14-errors.md)) |

কয়েকটি মান থেকে তৈরি একটি স্ট্রিং দেখাতে সেগুলো `+` দিয়ে জোড়া লাগান, অথবা
`$"{name} is {age}"`-এর মতো ইন্টারপোলেটেড স্ট্রিং ব্যবহার করুন
([অধ্যায় ১৬](16-text-and-arrays.md))। অ্যারে trace করা যায় না; আগে
`string.join` দিয়ে জোড়া লাগান।

`trace` একটি সংরক্ষিত বিল্ট-ইন। `trace` নামে কোনো ফাংশন বা ভেরিয়েবল ঘোষণা করা
যায় না।
