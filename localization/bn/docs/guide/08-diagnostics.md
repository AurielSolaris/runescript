> এটি [ইংরেজি মূল লেখার](../../../../docs/guide/08-diagnostics.md) অনুবাদ। পার্থক্য থাকলে ইংরেজি সংস্করণটিই সঠিক। অনুবাদটি AI-এর সাহায্যে করা এবং লেখক যাচাই করেছেন।

# ৮. ডায়াগনস্টিক তালিকা

প্রতিটি এরর সোর্সের ঠিক কোন জায়গায় সমস্যা, তা দেখিয়ে দেয়:

```text
prog.rsc:9:26: error ASX-TYPE-004: Cannot assign signed integer 'sint' to unsigned integer 'uint'.
        uint unsignedValue = signedValue;
                             ^^^^^^^^^^^
  help: Use an explicit checked conversion, (uint) x, or change the destination type.
```

`ASX` উপসর্গটি অস্থায়ী, এর নাম বদলাতে পারে। সংখ্যাগুলো একই থাকবে।

## লেক্সিক্যাল এরর

| কোড | অর্থ |
|---|---|
| `ASX-LEX-001` | এমন একটি অক্ষর যা ভাষার অংশ নয়, যেমন `#`, অথবা একা একটি `&` |
| `ASX-LEX-002` | একটি স্ট্রিং লিটারাল, লাইন শেষ হওয়ার আগে যার বন্ধ করার `"` নেই |
| `ASX-LEX-003` | অজানা এস্কেপ সিকোয়েন্স, যেমন `\q` |
| `ASX-LEX-004` | একটি `/*` কমেন্ট যা কখনো বন্ধ হয়নি |
| `ASX-LEX-005` | অবৈধ সংখ্যা: শুরুতে শূন্য (`007`), সঙ্গে লেগে থাকা অক্ষর (`12abc`), অতিরিক্ত দশমিক বিন্দু (`1.2.3`), অথবা খুব বড় বা খুব ছোট (`1e999`, `1e-999`) |
| `ASX-LEX-006` | এমন char লিটারাল, যাতে ঠিক একটি অক্ষর নেই: `''`, `'ab'` |
| `ASX-LEX-007` | ফাইলটি বৈধ UTF-8 নয় (যেমন Windows-1252-এ সেভ করা)। UTF-16 ও UTF-32 ফাইল বরং রূপান্তর করে নেওয়া হয় |
| `ASX-LEX-008` | একটি টেমপ্লেট, ট্যাগ, ইন্টারপোলেশন বা `$if`-এর শর্ত, যা কখনো বন্ধ করা হয়নি |

## সিনট্যাক্স এরর

| কোড | অর্থ |
|---|---|
| `ASX-PARSE-001` | অপ্রত্যাশিত কিছু, যেমন `;` বাদ পড়া, `package` বাদ পড়া, অ্যাক্সেস মডিফায়ার ছাড়া ফাংশন, AS3-ধাঁচের `function` কিওয়ার্ড, প্রাথমিক মান (initializer) বাদ পড়া |
| `ASX-PARSE-002` | এখনো তৈরি হয়নি এমন বৈশিষ্ট্যের জন্য সংরক্ষিত শব্দ (`class`, `char`, …) |

পার্সার প্রথম সিনট্যাক্স এররেই থেমে যায়।

## নামের এরর

| কোড | অর্থ |
|---|---|
| `ASX-NAME-001` | অসংজ্ঞায়িত ভেরিয়েবল বা ফাংশন |
| `ASX-NAME-002` | নামটি আগেই ঘোষিত: পুনরায় ঘোষণা, শ্যাডোয়িং, অথবা একই নামের দুটি ফাংশন |
| `ASX-NAME-003` | যা ফাংশন নয়, একটি ভেরিয়েবল, তাকে কল করা |
| `ASX-NAME-004` | বিল্ট-ইন `trace`-কে মান হিসেবে ব্যবহার করা |
| `ASX-NAME-005` | `trace` নামে একটি ফাংশন ঘোষণা করা |
| `ASX-NAME-006` | একটি প্যারামিটার বা ফাংশনে অ্যাসাইন করা |
| `ASX-NAME-007` | প্যাকেজের নাম স্কোপে নেই, যেমন `use "std:string";` ছাড়া `string.toUpper` |
| `ASX-NAME-008` | প্যাকেজে ওই নামে কোনো ফাংশন নেই (আপনি Go-র বানান লিখলে সাহায্য-বার্তা camelCase বানানটি সুপারিশ করে) |
| `ASX-NAME-009` | নেস্টেড ফাংশন বা ল্যাম্বডার ভেতরে বাইরের ফাংশনের ভেরিয়েবল ব্যবহার করা (ফাংশন ভেরিয়েবল ধরে রাখে না, রুন ছাড়া) |
| `ASX-NAME-010` | এমন প্রোটোটাইপ, যার ফাংশন কখনো সংজ্ঞায়িত হয়নি |
| `ASX-NAME-011` | এমন জায়গায় ফাংশন ব্যবহার, যেখানে তার অ্যাক্সেস মডিফায়ার তা নিষেধ করে: অন্য ফাইলের `private` ফাংশন, বা অন্য প্যাকেজের `protected` ফাংশন |

## `use`-এর এরর

| কোড | অর্থ |
|---|---|
| `ASX-USE-001` | অজানা স্ট্যান্ডার্ড লাইব্রেরি প্যাকেজ, যেমন `use "std:nope";` |
| `ASX-USE-002` | একই প্যাকেজ একই নামে দুবার ব্যবহার করা হয়েছে |
| `ASX-USE-003` | `use`-এর এমন রূপ যা এখনো সমর্থিত নয়, যেমন `go:` প্যাকেজ |
| `ASX-USE-004` | ব্যবহৃত ফাইলটি নেই, অথবা প্যাকেজের ডিরেক্টরিতে কোনো `.rsm` ফাইল নেই (দুটিই ওয়ার্কিং ডিরেক্টরির সাপেক্ষে) |
| `ASX-USE-005` | প্যাকেজগুলো একটি চক্রে একে অপরকে ব্যবহার করে; বার্তাটি চক্রটি দেখায় |
| `ASX-USE-006` | বৈধ প্যাকেজ নাম নয়, যেমন `"1abc"` বা `"if.then"`, অথবা `\` দিয়ে লেখা পাথ |
| `ASX-USE-007` | প্যাকেজের ডিরেক্টরির কোনো `.rsm` ফাইল ভিন্ন একটি প্যাকেজ ঘোষণা করে |
| `ASX-USE-008` | একই ফাইলের দুটি `use`-এর কোয়ালিফায়ার একই হয়ে যাবে; একটিকে `as` দিয়ে অন্য নাম (alias) দিন |
| `ASX-USE-009` | একটি extern অজানা `rune:` মডিউলের নাম দেয়, অথবা এমন ফাংশনের যা সেই মডিউলে নেই |

## টাইপের এরর

| কোড | অর্থ |
|---|---|
| `ASX-TYPE-001` | বেমানান টাইপ, যেমন `int x = "a";` |
| `ASX-TYPE-002` | `void`-কে মান হিসেবে, বা ভেরিয়েবল/প্যারামিটারের টাইপ হিসেবে ব্যবহার |
| `ASX-TYPE-003` | আর্গুমেন্টের সংখ্যা ভুল |
| `ASX-TYPE-004` | **সাইনড পূর্ণসংখ্যাকে `uint` হিসেবে অ্যাসাইন, পাস বা রিটার্ন করা** |
| `ASX-TYPE-005` | `uint`-কে সাইনড পূর্ণসংখ্যা হিসেবে অ্যাসাইন, পাস বা রিটার্ন করা |
| `ASX-TYPE-006` | কনস্ট্যান্টটি তার টাইপের জন্য খুব বড় বা খুব ছোট |
| `ASX-TYPE-007` | ঋণাত্মক কনস্ট্যান্টকে `uint` হিসেবে ব্যবহার |
| `ASX-TYPE-008` | ফাংশনটি কোনো মান রিটার্ন না করেই শেষ হয়ে যেতে পারে |
| `ASX-TYPE-009` | `void` ফাংশনে `return value;`, অথবা non-void ফাংশনে শুধু `return;` |
| `ASX-TYPE-010` | অজানা টাইপের নাম |
| `ASX-TYPE-011` | একই অপারেটরে সাইনড ও আনসাইনড অপারেন্ড মেশানো |
| `ASX-TYPE-012` | এই অপারেন্ড টাইপগুলোর জন্য অপারেটরটি সংজ্ঞায়িত নয়, অথবা একটি ফাংশন মান `trace` করা |
| `ASX-TYPE-013` | শর্তটি `bool` নয় |
| `ASX-TYPE-014` | কনস্ট্যান্ট শূন্য দিয়ে ভাগ |
| `ASX-TYPE-015` | ফাংশনের সংজ্ঞা তার প্রোটোটাইপের সঙ্গে মেলে না |
| `ASX-TYPE-016` | যে মান ফাংশন নয়, তাকে কল করা, যেমন `(1)(2)` |
| `ASX-TYPE-017` | অনুমোদিত নয় এমন রূপান্তর, যেমন `(int) true`, অথবা কোনো এরর `e`-র জন্য `(string) e` |
| `ASX-TYPE-018` | এমন কনস্ট্যান্ট, যা তার ফ্লোট টাইপ হুবহু প্রকাশ করতে পারে না, যেমন `float32 f = 0.1;` (লিখুন `(float32) 0.1`) |
| `ASX-TYPE-019` | এরর টাইপ ছাড়া অন্য কিছুর `new` |
| `ASX-TYPE-020` | এমন ফিল্ড যা নেই, যেমন `e.what`, এরর নয় এমন মানের ফিল্ড, অথবা `e.toString()`-এর মতো মেথড কল |
| `ASX-TYPE-021` | এরর নয় এমন মান `throw` করা, অথবা এমন catch ক্লজ যার টাইপ এরর টাইপ নয় |
| `ASX-TYPE-022` | এমন catch ক্লজ যা কখনো চলবে না, কারণ আগের একটি ক্লজ তার টাইপ আগেই ধরে ফেলে |
| `ASX-TYPE-023` | একটি extern ফাংশনের প্যারামিটার বা ফলাফলের টাইপ JavaScript-এর সীমানা পার হতে পারে না, যেমন একটি ফাংশন টাইপ |
| `ASX-TYPE-024` | একটি `rune:` ফাংশনের extern ঘোষণা সেই ফাংশনের টাইপের সাথে মেলে না |
| `ASX-TYPE-025` | ভুল টাইপ আর্গুমেন্ট: `Array` একটি এলিমেন্ট টাইপ নেয় (`Array<string>`), `Signal` একটি সংখ্যা, `bool` বা `string` টাইপ নেয় (`Signal<int>`); অন্য টাইপ কোনোটি নেয় না |
| `ASX-TYPE-026` | এমন স্ট্রাক্ট লিটারাল, যাতে কোনো ফিল্ড বাদ পড়েছে, কোনোটি দুবার আছে, বা এমন ফিল্ড আছে যা স্ট্রাক্টে নেই: `Point{x: 1}` |
| `ASX-TYPE-027` | এমন স্ট্রাক্ট, যা মান হিসেবে নিজেকেই ধারণ করে, সরাসরি বা অন্য স্ট্রাক্টের মাধ্যমে; বদলে একটি `Array`-এ রাখুন |

## টেমপ্লেটের এরর

টেমপ্লেট `rune:dom`-এর অংশ ([অধ্যায় ১৫](15-web-pages.md))।

| কোড | অর্থ |
|---|---|
| `ASX-TMPL-001` | একটি `template` ব্লক, যা `Element` ফেরত দেওয়া কোনো ফাংশনের শেষ স্টেটমেন্ট নয় |
| `ASX-TMPL-002` | এমন একটি এলিমেন্ট, যা HTML4, HTML5 বা SVG তালিকায় নেই (এটি অন্য নেমস্পেসে থাকলে বা কেবল অক্ষরের ছোট-বড়তে আলাদা হলে help তা জানায়) |
| `ASX-TMPL-003` | এমন একটি অ্যাট্রিবিউট, যা এলিমেন্টটির নেই |
| `ASX-TMPL-004` | এমন একটি স্থির অ্যাট্রিবিউট মান, যা অ্যাট্রিবিউটটি নিতে পারে না: বুলিয়ান অ্যাট্রিবিউটে মান, তালিকার বাইরের কিওয়ার্ড, ভুল সংখ্যা বা দৈর্ঘ্য, স্ক্রিপ্ট চালাবে এমন URL, অথবা ইভেন্ট হ্যান্ডলারের জন্য লেখা |
| `ASX-TMPL-005` | ভুল টাইপের একটি `{{ }}` মান, যেমন পড়া হয়নি এমন একটি রুন (`{{ count }}`), অথবা লেখার অ্যাট্রিবিউটের জন্য একটি `int` |
| `ASX-TMPL-006` | একই এলিমেন্টে একই অ্যাট্রিবিউট দুবার |
| `ASX-TMPL-007` | `use "rune:dom";` ছাড়া একটি ফাইলে টেমপ্লেট |

## কম্পাইলের সময়ের অন্যান্য এরর

| কোড | অর্থ |
|---|---|
| `ASX-FLOW-001` | লুপের বাইরে `break` বা `continue` |
| `ASX-ENTRY-001` | কোনো `main` ফাংশন নেই |
| `ASX-ENTRY-002` | `main`-এর প্যারামিটার আছে, অথবা এটি `int`/`void` ছাড়া অন্য কিছু রিটার্ন করে |
| `ASX-ENTRY-003` | একাধিক ফাইল `main` সংজ্ঞায়িত করে; একটি প্রোগ্রামে ঠিক একটি থাকে |
| `ASX-TARGET-002` | `runescript run`-কে এমন একটি প্রোগ্রাম দেওয়া হয়েছে, যা কেবল JavaScript টার্গেট চালাতে পারে: এতে extern ফাংশন আছে, অথবা এটি `rune:dom` ব্যবহার করে |

## সতর্কবার্তা (warnings)

সতর্কবার্তা এমন কোডের দিকে নির্দেশ করে যা বৈধ, কিন্তু সম্ভবত ভুল। প্রোগ্রামটি
তবুও চলে:

```text
prog.rsc:3:9: warning ASX-WARN-001: variable 'unused' is never used
        int unused = 1;
            ^
  help: remove the declaration
```

সতর্কবার্তা কেবল তখনই দেখানো হয় যখন প্রোগ্রামে কোনো এরর নেই, কারণ এরর থেকে
প্রায়ই এমন সতর্কবার্তা আসে যা এরর ঠিক করলেই চলে যায়। `runescript run`,
`check`, এবং `build` তিনটিই দুটি ফ্ল্যাগ নেয়:

- `-Werror` প্রতিটি সতর্কবার্তাকে এরর বানায়: প্রোগ্রামটি চলে না বা বিল্ড হয়
  না, এবং প্রতিটি সতর্কবার্তা `error ASX-WARN-…: … [-Werror]` হিসেবে দেখানো হয়।
- `--allow <codes>` তালিকাভুক্ত সতর্কবার্তাগুলো আর দেখায় না, যেমন
  `--allow ASX-WARN-002` বা `--allow WARN-002,WARN-005`। ফ্ল্যাগটি একাধিকবার
  দেওয়া যায়।

| কোড | অর্থ |
|---|---|
| `ASX-WARN-001` | একটি লোকাল ভেরিয়েবল কখনো পড়া হয় না। এতে মান দেওয়া, `x += 1` এবং `x++` সহ, পড়া হিসেবে গণ্য হয় না |
| `ASX-WARN-002` | একটি ফাংশন বা ল্যাম্বডার প্যারামিটার কখনো পড়া হয় না। `catch` ক্লজের ভেরিয়েবলের জন্য কখনো সতর্ক করা হয় না |
| `ASX-WARN-003` | একটি `use` ঘোষণা, যার কোয়ালিফায়ার কখনো ব্যবহার হয় না |
| `ASX-WARN-004` | যে স্টেটমেন্ট কখনো চলতে পারে না, কারণ সেগুলো একটি `return`, `throw`, `break`, বা `continue`-এর পরে আসে (অথবা এমন `if`/`try`-এর পরে যার প্রতিটি পথ এর একটিতে শেষ হয়)। লুপ বিবেচনা করা হয় না, তাই `while (true) { }`-এর পরের কোডের জন্য সতর্ক করা হয় না |
| `ASX-WARN-005` | স্টেটমেন্ট হিসেবে ব্যবহৃত একটি কল, যার ফলাফল `void` নয়, ফেলে দেওয়া হয় |
| `ASX-WARN-006` | একটি extern কোনো একটি হোস্টের নিজস্ব মডিউলের নাম দেয়, যেমন `"node:fs"`; হোস্ট-নিরপেক্ষ `rune:` মডিউল ব্যবহার করাই ভালো |
| `ASX-WARN-007` | এমন একটি এলিমেন্ট বা অ্যাট্রিবিউট, যা HTML5 বা SVG 2 অপ্রচলিত করেছে, যেমন `<center>`, `bgcolor`, `xlink:href`; help বিকল্পটির নাম জানায় |
| `ASX-WARN-008` | এমন একটি সিলেক্টরসহ `dom.renderApp`, যা একটিমাত্র id নয়, যেমন `".app"`: এটি একাধিক এলিমেন্ট মেলাতে পারে, অথবা একটিও নয় |

## রানটাইম এরর

এগুলো প্রোগ্রামটিকে এক্সিট স্ট্যাটাস 1 দিয়ে থামিয়ে দেয়, যদি না একটি `try`
স্টেটমেন্ট এদের ধরে (দেখুন [অধ্যায় ১৪](14-errors.md))। এররের আগে যা কিছু `trace`
করা হয়েছে, তা আগেই দেখানো হয়ে গেছে।

| কোড | অর্থ | যে হিসেবে ধরা হয় |
|---|---|---|
| `ASX-RUN-001` | ১০,০০০-এর বেশি গভীর পর্যন্ত নেস্টেড কল (সাধারণত নিয়ন্ত্রণহীন রিকার্শন) | ধরা যায় না |
| `ASX-RUN-002` | পূর্ণসংখ্যা ওভারফ্লো: ফলটি তার টাইপে আঁটে না (ফ্লোট এর বদলে `Infinity` হয়ে যায়) | `RangeError` |
| `ASX-RUN-003` | পূর্ণসংখ্যাকে শূন্য দিয়ে ভাগ বা ভাগশেষ (ফ্লোটে ফল হয় `Infinity` বা `NaN`) | `RangeError` |
| `ASX-RUN-004` | স্ট্যান্ডার্ড লাইব্রেরির কোনো ফাংশন ব্যর্থ হয়েছে, যেমন ঋণাত্মক সংখ্যা দিয়ে `string.repeat`, অথবা সীমার বাইরের বা কোনো অক্ষরের মাঝখানের সীমানা দিয়ে `string.slice` | `Error`; `string.slice`-এর জন্য `RangeError` |
| `ASX-RUN-005` | `new` দিয়ে তৈরি একটি এরর throw করা হয়েছে এবং কেউ তা ধরেনি | |
| `ASX-RUN-006` | একটি রূপান্তর ব্যর্থ হয়েছে, যেমন রানটাইমে `(int) "12x"` বা `(uint) -1` | `TypeError` বা `RangeError` |
| `ASX-RUN-007` | একটি JavaScript ফাংশন এমন মান ফেরত দিয়েছে যা তার extern ঘোষণার সাথে মেলে না, যেমন `int`-এর জন্য `1.5` | `TypeError` |
| `ASX-RUN-008` | একটি JavaScript ফাংশন এক্সেপশন থ্রো করেছে, অথবা তার মডিউলে এমন কোনো ফাংশন নেই | `Error` |
| `ASX-RUN-009` | `dom.renderApp` তার সিলেক্টরের সঙ্গে মেলে এমন কোনো এলিমেন্ট পায়নি | `Error` |
| `ASX-RUN-010` | একটি বাঁধা অ্যাট্রিবিউট এমন মান পেয়েছে, যা সেটি নিতে পারে না: তালিকার বাইরের কিওয়ার্ড, অথবা স্ক্রিপ্ট চালাবে এমন URL | `TypeError` |
| `ASX-RUN-011` | অ্যারের সীমার বাইরের ইনডেক্স (`a[i]`, যেখানে `i < 0` বা `i >= a.length`), অথবা খালি অ্যারেতে `pop()` | `RangeError` |
| `ASX-RUN-012` | 0 থেকে প্রস্থ বিয়োগ 1-এর বাইরের শিফট সংখ্যা, যেমন `x` একটি `int` হলে `x << 40` | `RangeError` |

JavaScript টার্গেটে, ১০,০০০ কলের আগেই হোস্টের নিজের স্ট্যাক ফুরিয়ে গেলেও
`ASX-RUN-001` জানানো হয় (দেখুন [অধ্যায় ১১](11-javascript.md))।
