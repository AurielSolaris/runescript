> এটি [ইংরেজি মূল লেখার](../../../../docs/guide/17-no-null-any-generics.md) অনুবাদ। পার্থক্য থাকলে ইংরেজি সংস্করণটিই সঠিক। অনুবাদটি AI-এর সাহায্যে করা এবং লেখক যাচাই করেছেন।

# ১৭. `null` নেই, `any` নেই, জেনেরিক নেই

বেশিরভাগ ভাষায় থাকা তিনটি জিনিস RuneScript বাদ রাখে: একটি `null` মান, সব কিছু ধরে এমন
একটি `any` টাইপ, এবং নিজে লেখা জেনেরিক। এই অধ্যায় ব্যাখ্যা করে কেন এতে টাইপ সিস্টেম
আরও শক্ত হয়, আর দেখায় `null` ছাড়া কীভাবে "এখানে কোনো মান নেই" বলা যায়: `false` দিয়ে।

## ঠিক কী কী নেই

| বৈশিষ্ট্য | RuneScript-এ | বদলে যা পান |
|---|---|---|
| `null`, `undefined`, `nil` | নেই (`ASX-NAME-001`) | প্রতিটি মান তার টাইপের একটি সত্যিকারের মান। "কোনো মান নেই" মানে একটি `bool`, যা `false` |
| `any`, `Object`, `*` | নেই (`ASX-TYPE-010`) | প্রতিটি ভেরিয়েবল, প্যারামিটার ও ফলের একটিই নির্দিষ্ট টাইপ |
| নিজের জেনেরিক ফাংশন ও টাইপ | ঘোষণা করা যায় না (`ASX-PARSE-001`) | যে টাইপের দরকার, তার জন্য ফাংশনটি লিখুন। বিল্ট-ইন `Array<T>` ও `Signal<T>`-ই একমাত্র টাইপ যা টাইপ আর্গুমেন্ট নেয়, এবং ভাষা নিজেই সেগুলো সংজ্ঞায়িত করে |

```actionscript
package main;

protected int main() {
    string name = null;   // error: ASX-NAME-001
    return 0;
}
```

```actionscript
package main;

protected int main() {
    any value = 5;   // error: ASX-TYPE-010
    return 0;
}
```

## এগুলো বাদ দিলে টাইপ কেন আরও শক্ত হয়

**`null` না থাকলে একটি টাইপের মানে ঠিক যা লেখা আছে তাই।** `null`-ওয়ালা ভাষায় একটি
`string` ভেরিয়েবলের আসল মানে "একটি স্ট্রিং, অথবা কিছুই না", আর প্রতিটি ব্যবহার এমন একটি
জায়গা যেখানে প্রোগ্রাম ক্র্যাশ করতে পারে। এর উদ্ভাবক টনি হোর একে তাঁর "বিলিয়ন ডলারের
ভুল" বলেছিলেন। RuneScript-এ একটি `string` সবসময় একটি স্ট্রিং: মান ছাড়া ঘোষিত ভেরিয়েবল
তার টাইপের শূন্য মান দিয়ে শুরু হয় (স্ট্রিংয়ের জন্য `""`, [অধ্যায় ৩](03-types-and-variables.md)),
যেসব টাইপের শূন্য মান নেই সেগুলো ইনিশিয়ালাইজ করতেই হয়, এবং কোনো অপারেশন খালি রেফারেন্স
তৈরি করে না। যখন সত্যিই একটি মান অনুপস্থিত থাকতে পারে, প্রোগ্রাম সেটি আলাদা একটি `bool` দিয়ে
বলে, যা আপনি দেখতে ও যাচাই করতে পারেন।

**`any` না থাকলে কম্পাইলার সবকিছু যাচাই করে।** `any` হলো টাইপ সিস্টেমের একটি ফুটো: যা
ঢোকে তা যাচাই ছাড়াই বেরিয়ে আসে, আর এরর দেখা দেয় কেবল প্রোগ্রাম চলার সময়, প্রায়ই তার
কারণ থেকে অনেক দূরে। TypeScript-এর `any` আর যাচাইহীন কাস্টের পথেই "টাইপ করা" প্রোগ্রামে
ভুল মান ঢোকে। RuneScript-এ এমন কোনো ফুটো নেই, আর সে কারণেই এটি JavaScript থেকে ফেরা
প্রতিটি মান যাচাই করতে পারে ([অধ্যায় ১১](11-javascript.md)): এমন কোনো টাইপ নেই, যা একটি
যাচাইহীন মানকে ঢুকতে দেবে।

**নিজের জেনেরিক না থাকলে প্রতিটি ফাংশনের একটিই নির্দিষ্ট সিগনেচার।** একটি জেনেরিক ফাংশনের
অর্থ নির্ভর করে কোন টাইপের সঙ্গে সেটি ব্যবহার হচ্ছে তার ওপর, তাই এর এরর দেখা দেয় কলের
জায়গায়, টাইপ ভেরিয়েবলের ভাষায়। RuneScript-এর ফাংশন ঠিক কী নেয় ও কী ফেরত দেয় তা বলে, এর
এরর বার্তায় থাকে আসল টাইপের নাম, আর কম্পাইল করা JavaScript-এর চলার সময় কোনো টাইপ-তথ্য
লাগে না। বিল্ট-ইন `Array<T>` জেনেরিকের সবচেয়ে সাধারণ প্রয়োজনটি মেটায়, যেকোনো কিছুর একটি
তালিকা, টাইপ সিস্টেমকে খুলে না দিয়েই।

খরচ হলো কিছু পুনরাবৃত্তি: একটি জেনেরিক `max`-এর বদলে একটি `maxInt` ও একটি `maxFloat64`।
এমন কোডের বিনিময়ে RuneScript এই খরচ মেনে নেয়, যার টাইপের ওপর সবসময় ভরসা করা যায়।

## `null`-এর জায়গায় `false`

`false` নিজে একটি অনুপস্থিত মানের জায়গা নিতে পারে না, কারণ একটি `string`-এ `bool` রাখা যায়
না (`ASX-TYPE-001`)। বরং যে মান অনুপস্থিত থাকতে পারে, তার সঙ্গে থাকে একটি `bool`, যা মান
না থাকা পর্যন্ত `false`, আর মান এলে `true`। তখন কম্পাইলার অনুপস্থিতিকে দৃশ্যমান করে: পাশে
ফ্ল্যাগটি ছাড়া আপনি মানটি পড়তে পারেন না।

### মানের পাশে একটি ফ্ল্যাগ

ফ্ল্যাগ ও একটি স্থানধারক মান একসঙ্গে ঘোষণা করুন, আর দুটিই একসঙ্গে সেট করুন:

```actionscript
package main;

protected int main() {
    bool hasWinner = false;   // false plays the role of null
    string winner = "";       // a placeholder; never read while hasWinner is false

    int score = 42;
    if (score > 40) {
        hasWinner = true;
        winner = "Ada";
    }

    if (hasWinner) {
        trace("winner:", winner);   // winner: Ada
    } else {
        trace("no winner yet");
    }
    return 0;
}
```

### যে ফাংশন হয়তো কিছুই খুঁজে পাবে না

একটি ফাংশন "একটি স্ট্রিং অথবা `false`" ফেরত দিতে পারে না, কারণ এর ফলের টাইপ একটিই।
শূন্য বা একটি এলিমেন্টের একটি অ্যারে ফেরত দিন: খালি মানে "পাওয়া যায়নি"। এর `length > 0`
হলো সেই `true`/`false`, যা আপনি যাচাই করেন:

```actionscript
package main;

use "std:string";

public Array<string> findUser(Array<string> users, string prefix) {
    for (int i = 0; i < users.length; i++) {
        if (string.hasPrefix(users[i], prefix)) {
            return [users[i]];
        }
    }
    return [];   // nothing found: the empty array is the "null"
}

protected int main() {
    Array<string> users = ["ada", "grace", "linus"];
    Array<string> found = findUser(users, "gr");
    bool ok = found.length > 0;
    if (ok) {
        trace("found", found[0]);   // found grace
    }
    trace(findUser(users, "zz").length > 0);   // false
    return 0;
}
```

### একটি প্রশ্ন ও একটি উত্তর

মান খোঁজা যখন সস্তা, প্রথমে `bool` ফেরত দেওয়া একটি ফাংশন দিয়ে জিজ্ঞেস করুন, তারপর মানটি
নিন। `string.contains` আর `string.index` এভাবেই একসঙ্গে কাজ করে:

```actionscript
package main;

use "std:string";

protected int main() {
    string line = "key=value";
    if (string.contains(line, "=")) {
        int at = string.index(line, "=");
        trace(string.slice(line, 0, at));   // key
    }
    return 0;
}
```

অবস্থান ফেরত দেওয়া ফাংশন "পাওয়া যায়নি" বোঝাতে `-1` ব্যবহার করে, Go-র মতো। এটি কাজ করে,
কারণ সত্যিকারের অবস্থান কখনো ঋণাত্মক নয়, তাই `-1`-কে ফল বলে ভুল হয় না।

### অনুপস্থিতি যখন একটি ভুল

অনুপস্থিত মান যখন বোঝায় যে কিছু ভুল হয়েছে, তখন কোনো ফ্ল্যাগই ফেরত দেবেন না। থ্রো করুন,
আর কলারকে সিদ্ধান্ত নিতে দিন ([অধ্যায় ১৪](14-errors.md)):

```actionscript
package main;

public int parsePort(string text) {
    int port = (int) text;   // throws TypeError if text isn't a number
    if (port < 1 || port > 65535) {
        throw new RangeError("port out of range: " + text);
    }
    return port;
}

protected int main() {
    try {
        trace(parsePort("8080"));   // 8080
        trace(parsePort("99999"));
    } catch (RangeError e) {
        trace(e.message);   // port out of range: 99999
    }
    return 0;
}
```

## প্যাটার্ন বাছাই

| মানটি অনুপস্থিত থাকতে পারে কারণ… | ব্যবহার করুন |
|---|---|
| এটি এখনো জানা নেই | একটি `bool` ফ্ল্যাগ, যা সেট না হওয়া পর্যন্ত `false` |
| খুঁজে কিছু পাওয়া যায়নি | শূন্য বা একটি এলিমেন্টের অ্যারে, অথবা অবস্থানের জন্য `-1` |
| কলার আগে জিজ্ঞেস করতে পারে | একটি `bool` প্রশ্ন, তারপর মান |
| কিছু ভুল হয়েছে | একটি এরর `throw` করুন |

একটি `struct` ফ্ল্যাগ আর মানকে একটি মানেই একসঙ্গে রাখে, যেমন `{ bool present; int value; }`,
যাতে দুটি আলাদা হয়ে না যায়: দেখুন অধ্যায় ১৯-এর ["কোনো মান নেই"-এর জন্য একটি স্ট্রাক্ট](19-structs.md)।
