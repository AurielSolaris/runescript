# ১৮. সংখ্যার গভীরে: প্রস্থ, লিটারাল, বিট, এবং `std:math`

[অধ্যায় ৩](03-types-and-variables.md)-এ `int`, `uint` ও ফ্লোট টাইপগুলোর পরিচয় দেওয়া
হয়েছে। এই অধ্যায়ে বাকিগুলো: নির্দিষ্ট প্রস্থের পূর্ণসংখ্যা, সংখ্যা লেখার অন্য উপায়, বিট
অপারেশন, এবং `std:math` লাইব্রেরি।

## নির্দিষ্ট প্রস্থের পূর্ণসংখ্যা

`int` ও `uint` ছাড়াও ঠিক ৮, ১৬, ৩২ ও ৬৪ বিটের পূর্ণসংখ্যা টাইপ আছে:

| টাইপ | পরিসর |
|---|---|
| `int8` | −128 … 127 |
| `int16` | −32768 … 32767 |
| `int32` | −2147483648 … 2147483647 |
| `int64` | −9223372036854775808 … 9223372036854775807 |
| `uint8` | 0 … 255 |
| `uint16` | 0 … 65535 |
| `uint32` | 0 … 4294967295 |
| `uint64` | 0 … 18446744073709551615 |

```actionscript
package main;

public void main() {
    uint8 red = 255;
    int64 population = 8_100_000_000;
    uint64 hash = 14695981039346656037;
    trace(red, population, hash);
}
```

প্রতিটি পূর্ণসংখ্যা টাইপ নিজেই একটি আলাদা টাইপ, তাই এদের মধ্যে কিছুই নিজে থেকে রূপান্তরিত
হয় না, এমনকি বড় টাইপেও না। স্পষ্টভাবে রূপান্তর করুন:

```actionscript
package main;

public void main() {
    int8 small = 100;
    int16 wider = (int16) small;   // fine: an explicit conversion
    int64 total = (int64) wider * 1_000_000;
    trace(wider, total);
    int16 oops = small;            // error: ASX-TYPE-001
}
```

`int32`-ও `int` নয়: `int` হলো সাধারণ পূর্ণসংখ্যা, যার একদিন কোনো মানের বেশি জায়গা
লাগলে প্রসারিত হওয়ার কথা, আর একটি `int32` কখনো তা হবে না।

`int`-এর মতোই প্রতিটি প্রস্থে গণনা যাচাই করা হয়: যে ফল টাইপে আঁটে না, তা ঘুরে যাওয়ার
বদলে একটি `RangeError` ছোড়ে।

```actionscript
package main;

public void main() {
    uint8 level = 250;
    try {
        level += 10;
        trace(level);
    } catch (RangeError e) {
        trace(e.message);   // integer overflow: 250 + 10 = 260 does not fit in 'uint8'
    }
}
```

## সংখ্যা লেখা

পূর্ণসংখ্যা হেক্স, বাইনারি বা অক্টালে লেখা যায়, আর যেকোনো সংখ্যায় `_` দিয়ে অঙ্ক আলাদা
করা যায়:

| রূপ | উদাহরণ | মান |
|---|---|---|
| দশমিক | `1_000_000` | 1000000 |
| হেক্স | `0xFF`, `0xDEAD_BEEF` | 255, 3735928559 |
| বাইনারি | `0b1010_0101` | 165 |
| অক্টাল | `0o755` | 493 |
| ফ্লোট | `1_234.5`, `6.022_140_76e23` | |

প্রিফিক্সগুলো ছোট হাতের অক্ষরে, আর `_` থাকতে হবে দুটি অঙ্কের মাঝে। শুরুতে শূন্য, যেমন
`0755`, একটি এরর (`ASX-LEX-005`), যাতে একে অক্টাল বলে ভুল না হয়।

## বিট অপারেশন

| অপারেটর | অর্থ |
|---|---|
| `a & b` | যে বিট দুটোতেই সেট |
| `a \| b` | যে বিট যেকোনো একটিতে সেট |
| `a ^ b` | যে বিট ঠিক একটিতে সেট |
| `~a` | টাইপের প্রস্থের মধ্যে প্রতিটি বিট উল্টানো |
| `a << n` | `n` বিট বাঁয়ে সরানো |
| `a >> n` | `n` বিট ডানে সরানো |

প্রতিটির একটি অ্যাসাইনমেন্ট রূপও আছে: `&=`, `|=`, `^=`, `<<=`, `>>=`।

```actionscript
package main;

public void main() {
    uint8 flags = 0b0000_0101;
    flags |= 0b1000_0000;           // set a bit
    flags &= ~((uint8) 0b0100);     // clear a bit
    trace(flags, (flags & 0b1000_0000) != 0);   // 129 true

    uint32 color = 0xFF8800;
    uint32 red = (color >> 16) & 0xFF;
    uint32 green = (color >> 8) & 0xFF;
    trace(red, green, color & 0xFF);            // 255 136 0
}
```

- `&`, `|` ও `^` একই টাইপের দুটি পূর্ণসংখ্যা নেয়।
- `>>` চিহ্নযুক্ত সংখ্যার চিহ্ন রাখে: `-16 >> 2` হলো `-4`।
- শিফটের সংখ্যা হতে হবে 0 থেকে প্রস্থ বিয়োগ 1 পর্যন্ত, তাই একটি `int`-এর জন্য 0 থেকে
  31। অন্য কিছু হলে এরর (চলার সময় একটি `RangeError`, `ASX-RUN-012`)।
- `<<` কখনো চুপচাপ বিট হারায় না। ফল টাইপে না আঁটলে সেটি একটি ওভারফ্লো এরর, ঠিক `*`-এর
  মতো। ইচ্ছে করে উঁচু বিট বাদ দিতে চাইলে আগে মানটি মাস্ক করুন।
- C ও ActionScript-এর মতো `&` `==`-এর চেয়ে আলগাভাবে বাঁধে, তাই `x & mask == 0` মানে
  `x & (mask == 0)`। এতে একটি পূর্ণসংখ্যা আর একটি `bool` মেশে, তাই কম্পাইলার একে থামায়।
  লিখুন `(x & mask) == 0`।

## `std:math`

`use "std:math";` Go-র [`math`](https://pkg.go.dev/math) প্যাকেজ নিয়ে আসে, camelCase
নামে, `float64`-এর ওপর কাজ করে:

```actionscript
package main;

use "std:math";

public void main() {
    float64 pi = math.pi;
    float64 angle = pi / 6;
    trace(math.sin(angle), math.cos(angle));    // 0.49999999999999994 0.8660254037844387
    trace(math.sqrt(2.0), math.pow(2.0, 10.0)); // 1.4142135623730951 1024
    trace(math.floor(-2.5), math.round(-2.5), math.roundToEven(2.5));   // -3 -3 2
    trace(math.max(3, 7), math.abs(-12), math.clamp(15, 0, 10));        // 7 12 10
}
```

| দল | ফাংশন |
|---|---|
| রাউন্ডিং | `abs`, `ceil`, `floor`, `trunc`, `round` (অর্ধেক শূন্য থেকে দূরে), `roundToEven` |
| ঘাত ও মূল | `sqrt`, `cbrt`, `pow`, `hypot`, `exp`, `exp2`, `expm1`, `ldexp` |
| লগারিদম | `log`, `log10`, `log2`, `log1p` |
| ত্রিকোণমিতি | `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `atan2` |
| হাইপারবোলিক | `sinh`, `cosh`, `tanh`, `asinh`, `acosh`, `atanh` |
| তুলনা ও অংশ | `min`, `max`, `mod`, `remainder`, `dim`, `copysign`, `signbit`, `nextafter` |
| বিশেষ মান | `isInf(x, sign)`, `inf(sign)`, `nan()` (এবং বিল্ট-ইন `isNaN`, `isFinite`) |
| পূর্ণসংখ্যা | `int`-এর ওপর `abs`, `min`, `max`, এবং `clamp(x, lo, hi)` |

**ধ্রুবক**, যেমন `math.pi`, `math.e`, `math.sqrt2`, `math.maxFloat64`, এবং `math.maxInt64`
বা `math.maxUint8` (প্রতিটি পূর্ণসংখ্যা টাইপের জন্য একটি), লিটারালের মতোই টাইপহীন: যেখানে
ব্যবহার হয় সেখানকার টাইপ নেয়, যদি আঁটে। `math.pi` রাউন্ড না করে একটি `float32`-এ রাখা যায়
না, তাই সেখানে লাগে `(float32) math.pi`।

**`min`, `max` ও `abs` `int` বা `float64`-এ কাজ করে।** প্রতিটি আর্গুমেন্ট একটি `int` বা
পূর্ণসংখ্যা লিটারাল হলে কম্পাইলার `int` সংস্করণটি নেয়, নইলে `float64`-এরটি। একটি `int`
ভেরিয়েবলের সঙ্গে একটি `float64` মেশানো এরর: একটিকে রূপান্তর করুন।

**অন্য সংখ্যা টাইপ আগে রূপান্তর করুন:** একটি `float` বা `float32`-এর জন্য
`math.sqrt((float64) f)`, একটি পূর্ণসংখ্যার জন্য `(float64) n`।

**সবখানে একই বিট।** প্রতিটি `std:math` ফাংশন ইন্টারপ্রেটার ও JavaScript-এ হুবহু একই ফল
দেয়, শেষ বিট পর্যন্ত, প্রতিটি কম্পিউটারে। JavaScript-এর নিজের `Math.sin` বা `Math.exp`
এক ব্রাউজার থেকে আরেকটিতে শেষ অঙ্কে আলাদা হতে পারে, তাই RuneScript সেগুলো ব্যবহার করে না:
দুটি টার্গেটই একই অ্যালগরিদম চালায়, Go-রটি।
