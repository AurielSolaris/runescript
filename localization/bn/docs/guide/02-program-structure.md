# ২. প্রোগ্রামের গঠন

## প্যাকেজ

প্রতিটি ফাইল একটি প্যাকেজ ঘোষণা দিয়ে শুরু হয়। এটি `;` দিয়ে শেষ হওয়া একটি একক
স্টেটমেন্ট, কোনো ব্লক নয়:

```actionscript
package games.puzzle.solver;

public void main() {
}
```

প্যাকেজের নাম হলো বিন্দু দিয়ে যুক্ত আইডেন্টিফায়ার। একটি প্রোগ্রাম একাধিক ফাইলে
ছড়িয়ে থাকতে পারে (দেখুন [প্যাকেজ ও ফাইল](../../../../docs/guide/12-packages-and-files.md))।

## প্যাকেজ ব্যবহার: `use`

`use` ঘোষণা আসে `package` লাইনের ঠিক পরে, কোনো ফাংশনের আগে। স্ট্যান্ডার্ড
লাইব্রেরির প্যাকেজ লেখা হয় `"std:<name>"` আকারে:

```actionscript
package main;

use "std:string";

public void main() {
    trace(string.toUpper("hello"));   // HELLO
}
```

এরপর ফাংশনগুলো ডাকা হয় প্যাকেজের কোয়ালিফায়ার (নামের শেষ অংশ) দিয়ে। দেখুন
[স্ট্যান্ডার্ড লাইব্রেরি: std:string](../../../../docs/guide/10-std-string.md)।

`use` অন্য RuneScript প্যাকেজ (`use "games.engine";`) এবং ফাইলও
(`use "./lib/helpers.rsc";`) লোড করে, তাই একটি প্রোগ্রাম একাধিক ফাইলে ছড়িয়ে থাকতে
পারে। দেখুন [প্যাকেজ ও ফাইল](../../../../docs/guide/12-packages-and-files.md)। Go প্যাকেজ
(`use "go:<package>";`) পরিকল্পিত, আর আজ এটি `ASX-USE-003` দেয়।

## কমেন্ট

```actionscript
package main;

// A line comment runs to the end of the line.

/* A block comment
   can span several lines. */

public void main() {
    trace("comments are ignored"); // trailing comments too
}
```

ব্লক কমেন্টের ভেতরে আরেকটি ব্লক কমেন্ট (নেস্টিং) চলে না।

## স্টেটমেন্ট ও ব্লক

- প্রতিটি স্টেটমেন্ট `;` দিয়ে শেষ হয়।
- বন্ধনী `{ }` একটি ফাংশন, `if`, `else`, `while` বা `for`-এর বডি চিহ্নিত করে।
  v0.1-এ এই বন্ধনী **বাধ্যতামূলক**, এমনকি একটিমাত্র স্টেটমেন্ট থাকলেও।

## প্রবেশবিন্দু: `main`

প্রোগ্রাম চালালে এর টপ-লেভেল `main` ফাংশনটি ডাকা হয়। `main` কোনো প্যারামিটার নেয়
না এবং `int` অথবা `void` ফেরত দেয়:

```actionscript
package main;

protected int main() {
    // do stuff
    return 0;
}
```

- `main` যদি `int` ফেরত দেয়, সেই মানটি প্রসেসের এক্সিট স্ট্যাটাস হয়।
- `main` যদি `void` হয়, এক্সিট স্ট্যাটাস 0।
- প্রতিটি ফাংশনের মতো `main`-ও একটি অ্যাক্সেস মডিফায়ার দিয়ে শুরু হয়: `public`,
  `protected` অথবা `private` (দেখুন [ফাংশন](06-functions.md))।

```actionscript
package main;

public void main() {
    trace("no return value needed");
}
```

কোনো ক্লাস লাগে না। প্রোগ্রাম তৈরি হয় টপ-লেভেল ফাংশন দিয়ে, যেগুলো যেকোনো ক্রমে
থাকতে পারে। ফাংশনের ভেতরেও ফাংশন রাখা (নেস্ট করা) যায়।

## নাম

আইডেন্টিফায়ার তৈরি হয় ASCII অক্ষর, অঙ্ক এবং `_` দিয়ে, আর অঙ্ক দিয়ে শুরু হতে পারে
না। বড় হাতের ও ছোট হাতের অক্ষর আলাদা ধরা হয়। `if`, `int`, `use` ও `return`-এর
মতো কিওয়ার্ড নাম হিসেবে ব্যবহার করা যায় না। ভবিষ্যতের বৈশিষ্ট্যের জন্য সংরক্ষিত
শব্দও (`class`, `struct`, `char`, `array`, `matrix`, এবং `int64`-এর মতো নির্দিষ্ট
আকারের পূর্ণসংখ্যা টাইপ) ব্যবহার করা যায় না।
