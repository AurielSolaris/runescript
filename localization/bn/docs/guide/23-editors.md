> এটি [ইংরেজি মূল লেখার](../../../../docs/guide/23-editors.md) অনুবাদ। পার্থক্য থাকলে ইংরেজি সংস্করণটিই সঠিক। অনুবাদটি AI-এর সাহায্যে করা এবং লেখক যাচাই করেছেন।

# ২৩. এডিটর

RuneScript চলে Visual Studio Code, Vim, Neovim আর Emacs-এ। প্রতিটির জন্য
[`editors/`](../../../../editors/README.md)-এ একটি প্যাকেজ আছে যা RuneScript হাইলাইট করে, আর সবগুলো
একই ল্যাঙ্গুয়েজ সার্ভার ব্যবহার করে, `runescript lsp`, যা `runescript` কমান্ডের ভেতরেই আছে।
ল্যাঙ্গুয়েজ সার্ভার আপনাকে দেয়:

- **লেখার সময়েই এরর।** সেভ করার আগেই কম্পাইলারের এরর আর সতর্কবার্তা কোডের নিচে দেখা যায়,
  তাদের কোড আর সাহায্য সহ, ঠিক যেভাবে `runescript check` সেগুলো জানায়।
- **হোভার।** কোনো নামের ওপর রাখলে তার টাইপ দেখায়, কোনো কলের ওপর রাখলে ফাংশনের সিগনেচার
  (স্ট্যান্ডার্ড লাইব্রেরির ফাংশনও), আর কোনো স্ট্রাক্টের ওপর রাখলে তার ফিল্ডগুলো।
- **সংজ্ঞায় যাওয়া** ভ্যারিয়েবল, প্যারামিটার, ফাংশন (অন্য ফাইল আর প্যাকেজেও), স্ট্রাক্ট, ফিল্ড,
  আর একটি `use` যে ফাইলগুলো লোড করে সেগুলোর জন্য।
- **কমপ্লিশন**: কিওয়ার্ড, স্কোপে থাকা নাম, ফাংশন, `csv.` বা `geom.`-এর পরে প্যাকেজের সদস্য,
  অ্যারের মেথড, স্ট্রাক্টের ফিল্ড, আর `use "…"`-এর ভেতরে `std:` প্যাকেজ।
- **একটি আউটলাইন**, ফাইলের স্ট্রাক্ট আর ফাংশনগুলোর।

## সেটআপ

প্রথমে RuneScript ইনস্টল করুন ([অধ্যায় ১](01-getting-started.md)) আর দেখে নিন যে একটি টার্মিনালে
`runescript version` কাজ করে। তারপর:

**Visual Studio Code।** [`editors/vscode`](../../../../editors/vscode/README.md) থেকে এক্সটেনশনটি
বিল্ড করে ইনস্টল করুন:

```sh
cd editors/vscode
npm install
npx vsce package
code --install-extension runescript-0.6.0.vsix
```

`runescript` আপনার `PATH`-এ না থাকলে সেটিংসে **RuneScript › Server: Path** সেট করুন।

**Vim আর Neovim।** [`editors/vim`](../../../../editors/vim/README.md) আপনার রানটাইম পাথে যোগ করুন।
Neovim 0.11 বা তার পরের সংস্করণে একটি লাইনেই ল্যাঙ্গুয়েজ সার্ভার চালু হয়:

```lua
vim.lsp.enable('runescript')
```

Vim-এ vim-lsp, coc.nvim বা ALE-কে `runescript lsp` কমান্ডের সঙ্গে যুক্ত করুন; প্লাগইনের README
প্রতিটির উপায় দেখায়।

**Emacs।** [`editors/emacs/runescript-mode.el`](../../../../editors/emacs/README.md) লোড করুন, তারপর
Eglot দিয়ে ল্যাঙ্গুয়েজ সার্ভার চালু করুন:

```elisp
(require 'runescript-mode)
(add-hook 'runescript-mode-hook #'eglot-ensure)
```

**অন্য যেকোনো এডিটর** যার ল্যাঙ্গুয়েজ সার্ভার ক্লায়েন্ট আছে: `.rsc` আর `.rsm` ফাইলের জন্য
`runescript lsp` চালান, যা স্ট্যান্ডার্ড ইনপুট ও আউটপুটে কথা বলে।

## আপনার কোড কীভাবে যাচাই হয়

ল্যাঙ্গুয়েজ সার্ভার আপনার প্রোগ্রাম যাচাই করে যেভাবে `runescript run` করত, তবে এখনো লেখা
হচ্ছে এমন কোডের জন্য একটু মানিয়ে নিয়ে:

- **use পাথ** মেলানো হয় ফাইলটি যে ওয়ার্কস্পেস ফোল্ডারে আছে তার সাপেক্ষে, যেমন `runescript run`
  সেগুলো মেলায় ওয়ার্কিং ডিরেক্টরির সাপেক্ষে। যে ফোল্ডার থেকে আপনি প্রোগ্রাম চালান সেটি খুলুন।
- **সেভ না করা পরিবর্তনও গোনা হয়।** এডিটরে খোলা ফাইলগুলো পড়া হয় এডিটর থেকে, তাই একটি ফাইলে
  কোনো ফাংশনের নাম বদলালে যে ফাইলগুলো সেটি ব্যবহার করে সেগুলোর এরর দেখা যায়, কোনোটি সেভ করার
  আগেই।
- **`main` ছাড়া ফাইল ঠিক আছে**, কারণ অন্য কোনো ফাইল সেটি ব্যবহার করতে পারে। নিজের প্যাকেজের
  ডিরেক্টরিতে থাকা একটি মডিউল (`.rsm`) যাচাই হয় প্যাকেজের বাকি অংশের সঙ্গে।
- **সতর্কবার্তা** দেখা যায় যখন প্রোগ্রামে আর কোনো এরর থাকে না, কমান্ড লাইনের মতোই।
