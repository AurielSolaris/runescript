# 4. אופרטורים

## חשבון

| אופרטור | משמעות | דוגמה | תוצאה |
|---|---|---|---|
| `+` | חיבור | `7 + 2` | `9` |
| `-` | חיסור | `7 - 9` | `-2` |
| `*` | כפל | `7 * 3` | `21` |
| `/` | חילוק (במספרים שלמים, מעוגל לכיוון אפס) | `-7 / 2` | `-3` |
| `%` | שארית (באותו סימן כמו הצד השמאלי) | `-7 % 2` | `-1` |
| `-` אונרי | היפוך סימן (רק במספרים שלמים עם סימן) | `-x` | |

</div>

```actionscript
package main;

public void main() {
    int x = 7;
    trace(x + 2, x - 9, x * 3, x / 2, x % 4, -x);   // 9 -2 21 3 3 -7
}
```

<div dir="rtl">

לשני האופרנדים חייב להיות אותו "סימניות": `int`/`sint` עם `int`/`sint`, או `uint`
עם `uint`. ליטרל מספרי מתאים את עצמו לאופרנד השני, ולכן `u + 1` עובד כש-`u` הוא
`uint`. אותם אופרטורים (חוץ מ-`%`) עובדים גם על מספרים עשרוניים; ראו
[מספרים עשרוניים והמרות](13-floats-and-conversions.md).

### גלישה לעולם אינה "מתגלגלת" בשקט

אם התוצאה של פעולה על מספרים שלמים אינה נכנסת בטיפוס שלה, התוכנית נעצרת עם שגיאת
זמן ריצה שמצביעה על הפעולה. הערך לעולם אינו מתגלגל:

</div>

```actionscript
package main;

public void main() {
    int x = 2147483647;
    x = x + 1;          // runtime error: ASX-RUN-002 integer overflow
}
```

<div dir="rtl">

תכנון השפה קובע שמספרים *יתרחבו* אוטומטית. ההרחבה של מספרים שלמים עדיין לא
תוכננה, ולכן RuneScript נעצרת במקום לנחש. גם חלוקה של מספר שלם באפס היא שגיאת זמן
ריצה (`ASX-RUN-003`). שתיהן הן `RangeError`, שהוראת `try` יכולה לתפוס (ראו
[שגיאות](14-errors.md)).

## השוואה

`==  !=  <  <=  >  >=` משווים שני מספרים שלמים בעלי אותה סימניות, או שני מספרים
עשרוניים מאותו טיפוס, ומחזירים `bool`. `==` ו-`!=` עובדים גם על שני ערכי `bool` או
על שתי מחרוזות `string`.

</div>

```actionscript
package main;

public void main() {
    int a = 1;
    int b = 2;
    string s = "rune";
    trace(a < b, a == b, s == "rune", true != false);   // true false true true
}
```

<div dir="rtl">

## לוגיקה

| אופרטור | משמעות |
|---|---|
| `a && b` | וגם: `b` מחושב רק אם `a` הוא `true` |
| `a \|\| b` | או: `b` מחושב רק אם `a` הוא `false` |
| `!a` | לא (שלילה) |

שני האופרנדים חייבים להיות `bool`. מספרים לעולם אינם נחשבים כאמת או שקר.

</div>

```actionscript
package main;

public void main() {
    int age = 30;
    bool adult = age >= 18 && !(age > 120);
    trace(adult);   // true
}
```

## קדימות

מהקשירה החזקה ביותר לחלשה ביותר:

1. `( … )`, קריאות לפונקציות
2. `-` אונרי, `!`, המרות `(T) x`
3. `*`, `/`, `%`
4. `+`, `-`
5. `<`, `<=`, `>`, `>=`
6. `==`, `!=`
7. `&&`
8. `||`

כל האופרטורים הבינאריים מקושרים משמאל: `10 - 4 - 3` הוא `(10 - 4) - 3`.

`+` גם מחבר שתי מחרוזות, ו-`==`, `!=`, `<`, `<=`, `>`, `>=` משווים שני `char`.
אף אחד מהם לא ממיר דבר: `"n=" + 5` היא שגיאה ([פרק 16](16-text-and-arrays.md)).
