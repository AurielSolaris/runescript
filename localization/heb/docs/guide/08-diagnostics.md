> זהו תרגום של [המקור באנגלית](../../../../docs/guide/08-diagnostics.md). אם יש הבדל, הגרסה האנגלית היא הקובעת. התרגום נעשה בעזרת בינה מלאכותית ונבדק בידי המחבר.

# 8. מדריך הודעות האבחון

כל שגיאה מצביעה על המיקום המדויק בקוד המקור:

</div>

```text
prog.rsc:9:26: error ASX-TYPE-004: Cannot assign signed integer 'sint' to unsigned integer 'uint'.
        uint unsignedValue = signedValue;
                             ^^^^^^^^^^^
  help: Use an explicit checked conversion, (uint) x, or change the destination type.
```

<div dir="rtl">

הקידומת `ASX` זמנית ועשויה לקבל שם אחר. המספרים יישארו כפי שהם.

## שגיאות לקסיקליות

| קוד | משמעות |
|---|---|
| `ASX-LEX-001` | תו שאינו חלק מהשפה, למשל `#`, או `&` בודד |
| `ASX-LEX-002` | ליטרל מחרוזת שאין לו `"` סוגר לפני סוף השורה |
| `ASX-LEX-003` | רצף מילוט (escape) לא מוכר, כמו `\q` |
| `ASX-LEX-004` | הערת `/*` שלא נסגרת לעולם |
| `ASX-LEX-005` | מספר לא תקין: אפס מוביל (`007`), אותיות צמודות (`12abc`), יותר מדי נקודות (`1.2.3`), או גדול או קטן מדי (`1e999`, `1e-999`) |
| `ASX-LEX-006` | סוג ליטרל שעדיין אינו נתמך: תווים (`'a'`) |
| `ASX-LEX-007` | הקובץ אינו UTF-8 תקין (למשל, נשמר ב-Windows-1252). קובצי UTF-16 ו-UTF-32 מומרים במקום זאת |

## שגיאות תחביר

| קוד | משמעות |
|---|---|
| `ASX-PARSE-001` | משהו לא צפוי, למשל `;` חסר, `package` חסר, פונקציה בלי משנה גישה, מילת המפתח `function` בסגנון AS3, אתחול חסר |
| `ASX-PARSE-002` | מילה שמורה לתכונה שעדיין לא מומשה (`class`, `char`, …) |

המנתח (parser) נעצר בשגיאת התחביר הראשונה.

## שגיאות שמות

| קוד | משמעות |
|---|---|
| `ASX-NAME-001` | משתנה או פונקציה שלא הוגדרו |
| `ASX-NAME-002` | השם כבר הוצהר: הצהרה חוזרת, הסתרה (shadowing) או פונקציה כפולה |
| `ASX-NAME-003` | קריאה למשהו שהוא משתנה ולא פונקציה |
| `ASX-NAME-004` | שימוש ב-`trace` המובנית כערך |
| `ASX-NAME-005` | הצהרה על פונקציה בשם `trace` |
| `ASX-NAME-006` | השמה לפרמטר או לפונקציה |
| `ASX-NAME-007` | מזהה החבילה אינו בטווח ההכרה, למשל `string.toUpper` בלי `use "std:string";` |
| `ASX-NAME-008` | אין בחבילה פונקציה בשם הזה (טקסט העזרה מציע את האיות ב-camelCase אם השתמשתם באיות של Go) |
| `ASX-NAME-009` | שימוש במשתנה של פונקציה עוטפת בתוך פונקציה מקוננת או ביטוי למבדה (פונקציות אינן לוכדות משתנים) |
| `ASX-NAME-010` | אב-טיפוס שהפונקציה שלו לא מוגדרת לעולם |
| `ASX-NAME-011` | שימוש בפונקציה במקום שמשנה הגישה שלה אוסר: פונקציה `private` של קובץ אחר, או פונקציה `protected` של חבילה אחרת |

## שגיאות `use`

| קוד | משמעות |
|---|---|
| `ASX-USE-001` | חבילה לא מוכרת של הספרייה הסטנדרטית, למשל `use "std:nope";` |
| `ASX-USE-002` | אותה חבילה בשימוש פעמיים תחת אותו שם |
| `ASX-USE-003` | צורת `use` שעדיין אינה נתמכת, למשל חבילות `go:` |
| `ASX-USE-004` | הקובץ שבשימוש אינו קיים, או שבתיקיית החבילה אין קובצי `.rsm` (שניהם יחסית לתיקיית העבודה) |
| `ASX-USE-005` | חבילות משתמשות זו בזו במעגל; ההודעה מציגה את המעגל |
| `ASX-USE-006` | שם חבילה לא תקין, למשל `"1abc"` או `"if.then"`, או נתיב שנכתב עם `\` |
| `ASX-USE-007` | קובץ `.rsm` בתיקיית חבילה מצהיר על חבילה אחרת |
| `ASX-USE-008` | לשני שימושים באותו קובץ יהיה אותו מזהה; תנו לאחד מהם כינוי עם `as` |

## שגיאות טיפוסים

| קוד | משמעות |
|---|---|
| `ASX-TYPE-001` | טיפוסים לא תואמים, למשל `int x = "a";` |
| `ASX-TYPE-002` | שימוש ב-`void` כערך, או כטיפוס של משתנה/פרמטר |
| `ASX-TYPE-003` | מספר ארגומנטים שגוי |
| `ASX-TYPE-004` | **מספר שלם עם סימן שמושם, מועבר או מוחזר כ-`uint`** |
| `ASX-TYPE-005` | `uint` שמושם, מועבר או מוחזר כמספר שלם עם סימן |
| `ASX-TYPE-006` | קבוע גדול או קטן מדי לטיפוס שלו |
| `ASX-TYPE-007` | קבוע שלילי שמשמש כ-`uint` |
| `ASX-TYPE-008` | הפונקציה עלולה להסתיים בלי להחזיר ערך |
| `ASX-TYPE-009` | `return value;` בפונקציית `void`, או `return;` ריק בפונקציה שאינה `void` |
| `ASX-TYPE-010` | שם טיפוס לא מוכר |
| `ASX-TYPE-011` | אופרנדים עם סימן ובלי סימן מעורבבים באותו אופרטור |
| `ASX-TYPE-012` | האופרטור אינו מוגדר לטיפוסי האופרנדים האלה, או `trace` של ערך פונקציה |
| `ASX-TYPE-013` | התנאי אינו `bool` |
| `ASX-TYPE-014` | חלוקה באפס קבוע |
| `ASX-TYPE-015` | הגדרת פונקציה אינה תואמת את אב-הטיפוס שלה |
| `ASX-TYPE-016` | קריאה לערך שאינו פונקציה, למשל `(1)(2)` |
| `ASX-TYPE-017` | המרה שאינה מותרת, למשל `(int) true` או `(string) e` עבור שגיאה `e` |
| `ASX-TYPE-018` | קבוע שטיפוס המספר העשרוני שלו אינו יכול לייצג במדויק, למשל `float32 f = 0.1;` (כתבו `(float32) 0.1`) |
| `ASX-TYPE-019` | `new` של משהו שאינו טיפוס שגיאה |
| `ASX-TYPE-020` | שדה שאינו קיים, למשל `e.what`, שדה של ערך שאינו שגיאה, או קריאה למתודה כמו `e.toString()` |
| `ASX-TYPE-021` | `throw` של ערך שאינו שגיאה, או פסוקית catch שהטיפוס שלה אינו טיפוס שגיאה |
| `ASX-TYPE-022` | פסוקית catch שלעולם לא תרוץ, כי פסוקית קודמת כבר תופסת את הטיפוס שלה |

## שגיאות הידור אחרות

| קוד | משמעות |
|---|---|
| `ASX-FLOW-001` | `break` או `continue` מחוץ ללולאה |
| `ASX-ENTRY-001` | אין פונקציית `main` |
| `ASX-ENTRY-002` | ל-`main` יש פרמטרים, או שהיא מחזירה משהו שאינו `int`/`void` |
| `ASX-ENTRY-003` | יותר מקובץ אחד מגדיר את `main`; לתוכנית יש בדיוק אחת |

## שגיאות זמן ריצה

אלה עוצרות את התוכנית עם קוד יציאה 1, אלא אם הוראת `try` תופסת אותן (ראו
[פרק 14](14-errors.md)). כל מה שהודפס ב-`trace` לפני השגיאה כבר הודפס.

| קוד | משמעות | נתפסת כ- |
|---|---|---|
| `ASX-RUN-001` | קריאות מקוננות לעומק של יותר מ-10,000 (בדרך כלל רקורסיה שיצאה משליטה) | אי אפשר לתפוס |
| `ASX-RUN-002` | גלישה במספר שלם: התוצאה אינה נכנסת בטיפוס שלה (מספרים עשרוניים הופכים ל-`Infinity` במקום זאת) | `RangeError` |
| `ASX-RUN-003` | חלוקה או שארית של מספר שלם באפס (במספרים עשרוניים התוצאה היא `Infinity` או `NaN`) | `RangeError` |
| `ASX-RUN-004` | פונקציה של הספרייה הסטנדרטית נכשלה, למשל `string.repeat` עם מספר חזרות שלילי | `Error` |
| `ASX-RUN-005` | שגיאה שנוצרה עם `new` נזרקה ושום דבר לא תפס אותה | |
| `ASX-RUN-006` | המרה נכשלה, למשל `(int) "12x"` או `(uint) -1` בזמן ריצה | `TypeError` או `RangeError` |

ביעד JavaScript, `ASX-RUN-001` מדווחת גם כשהמחסנית של סביבת ההרצה עצמה נגמרת לפני
10,000 קריאות (ראו [פרק 11](11-javascript.md)).
