# 8. מדריך הודעות האבחון

כל שגיאה מצביעה על המיקום המדויק בקוד המקור:

</div>

```text
prog.rsc:9:26: error ASX-TYPE-004: Cannot assign signed integer 'sint' to unsigned integer 'uint'.
        uint unsignedValue = signedValue;
                             ^^^^^^^^^^^
  help: Use an explicit checked conversion, (uint) x, or change the destination type.
```

<div dir="rtl">

במסוף, `error` והחיצים שלה מוצגים באדום, `warning` בצהוב ו-`help:` בטורקיז.
`--color=never` מבטל זאת, `--color=always` משאיר את הצבעים גם כשהפלט הולך לקובץ או
לצינור, ומשתנה הסביבה `NO_COLOR` מבטל אותם במצב `auto`, ברירת המחדל.

## שגיאות לקסיקליות

| קוד | משמעות |
|---|---|
| `ASX-LEX-001` | תו שאינו חלק מהשפה, למשל `#`, או `&` בודד |
| `ASX-LEX-002` | ליטרל מחרוזת שאין לו `"` סוגר לפני סוף השורה |
| `ASX-LEX-003` | רצף מילוט (escape) לא מוכר, כמו `\q` |
| `ASX-LEX-004` | הערת `/*` שלא נסגרת לעולם |
| `ASX-LEX-005` | מספר לא תקין: אפס מוביל (`007`), אותיות צמודות (`12abc`), יותר מדי נקודות (`1.2.3`), או גדול או קטן מדי (`1e999`, `1e-999`) |
| `ASX-LEX-006` | ליטרל תו שאינו מכיל בדיוק תו אחד: `''`, `'ab'` |
| `ASX-LEX-007` | הקובץ אינו UTF-8 תקין (למשל, נשמר ב-Windows-1252). קובצי UTF-16 ו-UTF-32 מומרים במקום זאת |
| `ASX-LEX-008` | תבנית, תג, אינטרפולציה או תנאי של `$if` שלא נסגרו לעולם |

## שגיאות תחביר

| קוד | משמעות |
|---|---|
| `ASX-PARSE-001` | משהו לא צפוי, למשל `;` חסר, `package` חסר, פונקציה בלי משנה גישה, מילת המפתח `function` בסגנון AS3, הצהרה בלי `=` או `;` |
| `ASX-PARSE-002` | מילה שמורה לתכונה שעדיין לא מומשה (`class`, `char`, …) |

המנתח (parser) נעצר בשגיאת התחביר הראשונה.

## אזהרות

אזהרה מצביעה על קוד חוקי שכנראה מכיל טעות. התוכנית עדיין רצה:

</div>

```text
prog.rsc:3:9: warning ASX-WARN-001: variable 'unused' is never used
        int unused = 1;
            ^
  help: remove the declaration
```

<div dir="rtl">

אזהרות מדווחות רק כשאין בתוכנית שגיאות, כי שגיאות גוררות לעתים קרובות אזהרות
נלוות שנעלמות כשמתקנים אותן. `runescript run`, `check` ו-`build` מקבלות כולן
שני דגלים:

- `-Werror` הופך כל אזהרה לשגיאה: התוכנית לא רצה ולא נבנית, וכל אזהרה מוצגת
  כ-`error ASX-WARN-…: … [-Werror]`.
- `--allow <codes>` מפסיק לדווח על האזהרות שברשימה, למשל
  `--allow ASX-WARN-002` או `--allow WARN-002,WARN-005`. אפשר לחזור על הדגל.

| קוד | משמעות |
|---|---|
| `ASX-WARN-001` | משתנה מקומי שאף פעם לא נקרא. השמה אליו, כולל `x += 1` ו-`x++`, אינה נחשבת קריאה |
| `ASX-WARN-002` | פרמטר של פונקציה או למבדה שאף פעם לא נקרא. על המשתנה של פסוקית `catch` אין אזהרה לעולם |
| `ASX-WARN-003` | הצהרת `use` שהשם המסמן שלה (qualifier) אף פעם לא מוזכר |
| `ASX-WARN-004` | הוראות שלעולם לא ירוצו, כי הן באות אחרי `return`, `throw`, `break` או `continue` (או אחרי `if`/`try` שכל מסלול בו מסתיים באחת מהן). לולאות אינן נבדקות, ולכן על קוד אחרי `while (true) { }` אין אזהרה |
| `ASX-WARN-005` | קריאה שמשמשת כהוראה, והתוצאה שלה, שאינה `void`, נזרקת |
| `ASX-WARN-006` | הצהרת extern נותנת שם של מודול של סביבת הרצה אחת, למשל `"node:fs"`; עדיף מודול `rune:` שאינו תלוי בסביבה |
| `ASX-WARN-007` | אלמנט או מאפיין ש-HTML5 או SVG 2 הפכו למיושנים, למשל `<center>`, `bgcolor`, `xlink:href`; העזרה נותנת את החלופה |
| `ASX-WARN-008` | `dom.renderApp` עם בורר שאינו id יחיד, למשל `".app"`: הוא עשוי להתאים לכמה אלמנטים, או לאף אחד |
| `ASX-WARN-009` | למשתנה בבלוק מקונן יש שם של משתנה או פרמטר מבלוק חיצוני, והוא מסתיר אותו עד סוף הבלוק |

## שגיאות זמן ריצה

אלה עוצרות את התוכנית עם קוד יציאה 1, אלא אם הוראת `try` תופסת אותן (ראו
[פרק 14](14-errors.md)). כל מה שהודפס ב-`trace` לפני השגיאה כבר הודפס.

| קוד | משמעות | נתפסת כ- |
|---|---|---|
| `ASX-RUN-001` | קריאות מקוננות לעומק של יותר מ-10,000 (בדרך כלל רקורסיה שיצאה משליטה) | אי אפשר לתפוס |
| `ASX-RUN-002` | גלישה במספר שלם: התוצאה אינה נכנסת בטיפוס שלה (מספרים עשרוניים הופכים ל-`Infinity` במקום זאת) | `RangeError` |
| `ASX-RUN-003` | חלוקה או שארית של מספר שלם באפס (במספרים עשרוניים התוצאה היא `Infinity` או `NaN`) | `RangeError` |
| `ASX-RUN-004` | פונקציה של הספרייה הסטנדרטית נכשלה, למשל `string.repeat` עם מספר חזרות שלילי, או `string.slice` עם גבולות מחוץ לטווח או באמצע תו | `Error`; `RangeError` עבור `string.slice` |
| `ASX-RUN-005` | שגיאה שנוצרה עם `new` נזרקה ושום דבר לא תפס אותה | |
| `ASX-RUN-006` | המרה נכשלה, למשל `(int) "12x"` או `(uint) -1` בזמן ריצה | `TypeError` או `RangeError` |
| `ASX-RUN-007` | פונקציית JavaScript החזירה ערך שלא תואם את הצהרת ה-extern שלה, למשל `1.5` עבור `int` | `TypeError` |
| `ASX-RUN-008` | פונקציית JavaScript זרקה חריגה, או שאין במודול שלה פונקציה כזו | `Error` |
| `ASX-RUN-009` | `dom.renderApp` לא מצאה אלמנט שמתאים לבורר שלה | `Error` |
| `ASX-RUN-010` | מאפיין קשור קיבל ערך שהוא לא יכול לקבל: מילת מפתח שאינה ברשימה, או כתובת URL שתריץ סקריפט | `TypeError` |
| `ASX-RUN-011` | אינדקס מערך מחוץ לטווח (`a[i]` כאשר `i < 0` או `i >= a.length`), או `pop()` על מערך ריק | `RangeError` |
| `ASX-RUN-012` | מספר הזזות מחוץ לטווח 0 עד הרוחב פחות 1, למשל `x << 40` כאשר `x` הוא `int` | `RangeError` |

ביעד JavaScript, `ASX-RUN-001` מדווחת גם כשהמחסנית של סביבת ההרצה עצמה נגמרת לפני
10,000 קריאות (ראו [פרק 11](11-javascript.md)).
